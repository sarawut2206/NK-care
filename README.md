# กบข.นข. — ระบบทะเบียนสัญญาและรับชำระ

ระบบทะเบียนสัญญาเงินกู้ ทุนเรือนหุ้น และการรับชำระของกลุ่มบุคคล กบข.นข.
โรงเรียนมัธยมวัดหนองแขม

## โปรแกรมหลัก

[`index.html`](index.html) — ไฟล์เดียวจบ เปิดได้ 3 ทาง

| เปิดจาก | ข้อมูลเก็บที่ | เหมาะกับ |
|---|---|---|
| ลิงก์ Apps Script (ลงท้าย `/exec`) | Google Sheets | ใช้งานจริง กรรมการหลายคนเห็นข้อมูลชุดเดียวกัน |
| [GitHub Pages](https://sarawut2206.github.io/NK-care/) | ต้องตั้งค่า URL + รหัสเชื่อมต่อก่อน | เปิดดูจากที่อื่น |
| เปิดไฟล์จากเครื่องตรง ๆ | เบราว์เซอร์เครื่องนั้น | ลองใช้ / ดูข้อมูลสำรอง |

แท็บในโปรแกรม: ทะเบียนสัญญา · รับชำระ · สรุปและใบเสร็จ · พิมพ์สัญญา ·
คำนวณวงเงิน · ติดตามหนี้ · ทะเบียนคุม · **รายคน** · ตรวจสอบ

### งวด

ระบบสร้างรายการงวดจากข้อมูลจริงทุกครั้งที่วาดหน้าจอ ไล่ตั้งแต่ ม.ค.2568
ถึงเดือนปัจจุบัน และขยายเองตามข้อมูล ไม่ต้องแก้โค้ดเมื่อขึ้นปีใหม่

- เลขงวดของสัญญาเดิมยึดจากงวดอ้างอิง ม.ค.2569 ซึ่งเป็นงวดที่ `t0 + 1`
- งวดก่อนงวดแรกของสัญญา แสดงยอดที่รับจริง แต่ไม่นำมาประเมิน
  เพราะรวมอยู่ในยอดยกมาแล้ว
- งวดที่ยังไม่ถึงกำหนดชำระ (วันที่ 5 บวกผ่อนผัน 5 วัน) ไม่นับเป็นค้างชำระ

## ฝั่งเซิร์ฟเวอร์ — Google Apps Script

[`apps-script/Code.gs`](apps-script/Code.gs) — โค้ดที่วางใน Apps Script ของ Google Sheet ที่เก็บข้อมูล

| หน้าที่ | รายละเอียด |
|---|---|
| เสิร์ฟหน้าโปรแกรม | `doGet` คืน `index.html` ให้เปิดจากลิงก์ `/exec` ได้ตรง ๆ |
| เก็บและอ่านข้อมูล | เก็บทั้งก้อนเป็น JSON ในชีทซ่อน `_ข้อมูล` แบ่งเป็นท่อนละ 4 หมื่นตัวอักษร ฟิลด์ใหม่จึงไม่หล่นหาย |
| ชีทอ่านง่าย | เมนู → อัปเดตชีทอ่านง่าย แตกเป็น สมาชิก · บัญชีธนาคาร · สัญญา · รับชำระ |
| อ่านสลิปด้วย AI | ส่งรูปหรือ PDF ให้ Claude แล้วคืนรายการรับโอน บังคับรูปแบบผลลัพธ์ด้วย JSON schema |
| กันชนกัน | `LockService` กันสองคนบันทึกทับกัน |

### ติดตั้ง

1. เปิด Google Sheet ที่จะใช้เก็บข้อมูล → **ส่วนขยาย → Apps Script**
2. วาง `apps-script/Code.gs` ทับไฟล์ `Code.gs` แล้วสร้างไฟล์ HTML ชื่อ **index** วางเนื้อ `index.html` ลงไป
3. รีเฟรชหน้า Sheet จะมีเมนู **กบข.นข.** ขึ้นมา → **1) สร้างชีททั้งหมด**
4. เมนูเดียวกัน → **ตั้งค่ารหัสเชื่อมต่อ** และ **ตั้งค่ากุญแจ AI**
5. **Deploy → New deployment → Web app** · Execute as: **Me** · Who has access: **Anyone**
6. ทุกครั้งที่แก้ `Code.gs` ต้อง **Deploy → Manage deployments → ✏️ → New version → Deploy**

### สองทางที่เปิดโปรแกรมได้

| ทาง | ล็อกอิน | ต้องใช้รหัส | เหมาะกับ |
|---|---|---|---|
| ลิงก์ Apps Script `/exec` | บัญชี Google | ไม่ต้อง | ใช้งานประจำ ปลอดภัยที่สุด |
| GitHub Pages | ไม่ต้อง | ต้องใส่รหัสครั้งเดียวต่อเครื่อง | เปิดจากเครื่องที่ไม่ได้ล็อกอิน Google |

ที่อยู่ `/exec` ฝังไว้ในตัวโปรแกรมแล้ว (ตัวแปร `GAS_URL` ใน `index.html`)
เปลี่ยนที่เดียวเมื่อ Deploy ใหม่แล้วได้ลิงก์ใหม่

**รหัสเชื่อมต่อกับกุญแจ AI ไม่อยู่ในไฟล์ใด ๆ ของ repo นี้** ทั้งคู่เก็บใน Script properties
ของ Apps Script ตั้งผ่านเมนูในหน้า Sheet

## เครื่องมืออ่านสเตทเมนท์

[`tools/nk_statement.py`](tools/nk_statement.py) — อ่านสเตทเมนท์ธนาคารเป็นฐานข้อมูล
รองรับทั้งหน้าที่เป็นข้อความและหน้าที่เป็นรูปภาพในไฟล์เดียวกัน

- **หน้าข้อความ** ดึงคำพร้อมพิกัดด้วย PyMuPDF แล้วจัดเป็นแถวตามตำแหน่ง y
- **หน้ารูปภาพ** เรนเดอร์เป็น PNG แล้วให้ Claude อ่านเป็นข้อความ
  ผลถูกเก็บเป็นไฟล์ `.txt` ไว้ตรวจและแก้ด้วยมือได้ ครั้งต่อไปจะใช้ไฟล์เดิม ไม่เรียกซ้ำ
- **ตรวจทุกบรรทัด** ยอดคงเหลือก่อนหน้าบวกลบยอดรายการ ต้องเท่ากับยอดคงเหลือบรรทัดนั้น
  และผลรวมต้องตรงกับหัวกระดาษของธนาคาร ถ้าไม่ตรงจะรายงาน ไม่ปล่อยผ่าน

### ติดตั้งและใช้งาน

```bash
pip install pymupdf anthropic
```

วางไฟล์ PDF ไว้ในโฟลเดอร์เดียวกัน แล้วสั่ง

```bash
python tools/nk_statement.py
```

ถ้ามีหน้าที่เป็นรูปภาพและยังไม่เคยถอดข้อความ ต้องตั้งกุญแจก่อน

```bash
export ANTHROPIC_API_KEY=sk-ant-...
```

ตัวเลือกอื่น

| ตัวเลือก | ความหมาย |
|---|---|
| `--root <โฟลเดอร์>` | โฟลเดอร์ที่เก็บ PDF วางสคริปต์ไว้ที่ไหนก็รันได้ |
| `--out <โฟลเดอร์>` | โฟลเดอร์ผลลัพธ์ |
| `--ocr-dir <โฟลเดอร์>` | ที่เก็บข้อความที่ถอดจากหน้ารูปภาพ |
| `--members kbk-*.json` | ใส่ชื่อสมาชิกจากไฟล์สำรองของโปรแกรม |
| `--no-ai` | ไม่เรียก AI แม้จะตั้งกุญแจไว้ |

### ผลลัพธ์ในโฟลเดอร์ `out/`

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `dashboard.html` | แดชบอร์ดรายคนและรายการเดินบัญชีทั้งหมด เปิดได้เลยไม่ต้องต่อเน็ต |
| `paste_for_app.txt` | ข้อความสำหรับวางในโปรแกรม แท็บรับชำระ รายการซ้ำจะไม่ถูกนับซ้ำ |
| `transactions.csv` `transactions.json` | ทุกรายการที่อ่านได้ |
| `persons.json` | สรุปรายคน กี่ครั้ง รวมเท่าไร วันไหนบ้าง แยกงวด |
| `report.md` | รายงานการตรวจสอบรายสเตทเมนท์ |

## ความเป็นส่วนตัว
