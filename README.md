### เว็บใหม่: แดชบอร์ด (หน้าแรก)

สรุปภาพรวมของกองทุนเป็นกราฟ อ่านง่ายแบบพอร์ตการลงทุน — **คำนวณจากตัวเลขที่กรอกไว้ในทะเบียนเท่านั้น ไม่มีตัวเลขสมมติ**

- การ์ดสรุป 4 ใบ: ① ทุนเรือนหุ้นสะสมรวมทุกคน ② เงินกู้คงเหลือรวมทุกคน ③ ดอกเบี้ยรับสะสมตั้งแต่ต้นปีถึงเดือนล่าสุดที่บันทึก ④ คาดการณ์เงินคืนสมาชิก (ปันผลหุ้น + เฉลี่ยคืนดอกเบี้ย)
- กราฟ: พอร์ตรายเดือน (หุ้นสะสม เทียบ เงินกู้คงเหลือ) · โดนัทแยกตามประเภท (สามัญ / ดูแลกัน / ฝากหุ้น) · แท่งดอกเบี้ยรายเดือน · อันดับ 10 คนแรกของหุ้นและของหนี้
- ช่อง **ปันผลหุ้น % ต่อปี** และ **เฉลี่ยคืนดอกเบี้ย %** กรอกเองได้ เปลี่ยนแล้วกราฟและตัวเลขคำนวณใหม่ทันที (จำค่าไว้และบันทึกขึ้น Google Sheets ตามปกติ)
- ติ๊ก «ปรับตามจำนวนเดือน» = ปันผลเฉพาะเดือนที่เลือก (× เดือน/12) เหมือนแท็บใบสรุป + ปันผล ถ้าไม่ติ๊กจะเป็นยอดทั้งปีเต็ม · เลือกช่วงเดือนที่ดูได้ที่หัวหน้า
- สูตรเดียวกับแท็บใบสรุป + ปันผลทุกประการ (ตรวจแล้วยอดตรงกัน): ปันผลหุ้น = หุ้นล่าสุด × อัตรา × เดือน/12 · เฉลี่ยคืน = ดอกเบี้ยที่ชำระ × อัตรา × เดือน/12
- ตัวเลขที่ได้เป็น **ประมาณการ** ยังไม่ใช่มติที่ประชุม

### เว็บใหม่: กู้ยืม + ติดตามหนี้ (แท็บ 🏦)

รวมงานขอกู้และติดตามหนี้ของระบบเก่าไว้หน้าเดียว เรียงลงมา: ภาพรวม → ขอกู้สามัญ → ขอกู้ดูแลกัน → ติดตามหนี้ค้าง → ทะเบียนสัญญา (ตัวเลขหนี้/หุ้น/ค้างชำระจากทะเบียนใหม่ ข้อมูลสัญญา/ผู้ค้ำจากระบบเก่า)

- **ขอกู้ (สามัญ / ดูแลกัน)** — เลือกสมาชิกจากทะเบียนใหม่ ใส่ยอดที่หักได้/เดือน วงเงินที่ขอ หุ้นประจำ จำนวนงวด ระบบคำนวณเพดาน ยอดผ่อน ดอกเบี้ยรวม และตารางชำระหนี้ (สูตร 2569 เดียวกับระบบเก่า) · เตือนถ้ามีงวดค้าง มีหนี้เดิมในประเภทนั้น (กู้ทับได้เงินส่วนต่าง) · ดูแลกัน: เช็กวงเงินไม่เกิน 35,000 ไม่เกิน 36 งวด โควตารวม 150,000 และผู้กู้ไม่เกิน 10 ราย · พิมพ์แบบคำขอกู้ · พิมพ์ตารางชำระหนี้ A4 · «สร้างสัญญา & ไปพิมพ์เอกสาร» เข้าทะเบียนสัญญาแล้วพาไปพิมพ์สัญญา/สัญญาค้ำที่แท็บเดิม
- **ติดตามหนี้ค้าง** — นับจากรายการในทะเบียนใหม่ตั้งแต่ ม.ค.69 ด้วยนิยามเดียวกับสถานะ «ค้าง n งวด» ในทะเบียน: งวดที่เลยกำหนดแล้วและไม่มีรายการชำระ ติดต่อกันถึงงวดล่าสุด (จ่ายแล้วเริ่มนับใหม่ · ผ่อนผัน/หักหุ้นชดเชยแล้วไม่นับ · ไม่เทียบยอดกับงวดละ) · แยกค้าง 1–2 / 3–5 / 6+ งวด · ยอดค้างรวม · ส่งออก CSV · ออก **หนังสือเตือน** (แจ้งผู้กู้ / แจ้งผู้ค้ำ / ทวงถามครั้งสุดท้าย) พร้อมค่าธรรมเนียมทวงถามและดอกเบี้ยผิดนัดตามสัญญาข้อ 3
- **ทำสัญญาย้อนหลัง** (ผู้กู้ที่มีหนี้อยู่แล้วแต่ยังไม่มีสัญญา ทั้งสามัญและดูแลกัน) — กด «เตรียมร่างสัญญา» ระบบสร้างร่างให้ทุกคน โดยถอดวงเงินและจำนวนงวดจากงวดละ หุ้นประจำ หุ้นเพิ่ม และหนี้ยกมาในทะเบียน (ลองทุกจำนวนงวดแล้วเลือกตารางผ่อนที่ยอดคงเหลือตรงทะเบียนที่สุด · กู้ทับใช้ยอดกู้ใหม่จากรายการกู้ทับ) · ช่อง «ตรวจ» บอกว่าตารางผ่อนตามสัญญานี้ตรงกับหนี้ในทะเบียนหรือต่างกันเท่าไร · แก้วงเงิน/งวด/งวดละ/วันที่/เลขที่สัญญา ใส่ผู้ค้ำ (สามัญ 2 · ดูแลกัน 1) ได้ในตารางเลย · ⟲ ถอดค่าใหม่ · กรอกเลขบัตร/ที่อยู่ของผู้กู้และผู้ค้ำครั้งเดียว · เลือกเอกสาร (สัญญาเงินกู้ · สัญญาค้ำ · หนังสือยินยอม · ตารางชำระหนี้) แล้ว «พิมพ์ชุดสัญญาที่เลือก» ทีละคนหรือทีละกลุ่ม · เก็บในข้อมูลทะเบียนใหม่ (ขึ้น Sheets เอง ไม่ปนกับระบบเก่า) และใช้เป็นข้อมูลสัญญา/ผู้ค้ำในหนังสือเตือนต่อ
- **ทะเบียนสัญญา** — ทุกสัญญาที่ยังมีหนี้: เลขที่สัญญา วันที่ วงเงิน งวดละ ผู้ค้ำ (จากระบบเก่า) คู่กับหนี้คงเหลือและสถานะค้างจากทะเบียนใหม่ · กด «พิมพ์สัญญา» ไปแท็บพิมพ์สัญญา

### เว็บใหม่: ชำระโดยหักทุนเรือนหุ้นชดเชย (กรณีพิเศษ)

สำหรับสมาชิกที่โอนไม่ครบตามงวด และคณะกรรมการให้หักทุนเรือนหุ้นชำระส่วนที่ขาด — กล่อง **🧮 ชำระโดยหักทุนเรือนหุ้นชดเชย** ในหน้าสินเชื่อของคนนั้น (คนอื่นไม่กระทบ)

- นำเข้าตารางผ่อนให้มีรายการรายเดือนก่อน (ยอดตามงวด) แล้วเลือกช่วงเดือน ใส่ **เงินสดที่รับจริง** รายเดือน และอ้างอิงมติ ระบบคำนวณส่วนที่หักหุ้นให้
- ยอดตามงวด = เงินสดที่รับจริง + ส่วนที่หักจากทุนเรือนหุ้น · หนี้ลดตามตารางครบ · หุ้นเพิ่มตามงวดแล้วหักส่วนที่ขาดออก · เดือนที่หักหุ้นไม่ถูกนับเป็นค้าง
- ใบเสร็จแสดง «ยอดตามงวด» «รับเงินสดจริง» «หักจากทุนเรือนหุ้น» แยกกัน พร้อมอ้างอิงมติ · ทะเบียนคุมมีคอลัมน์ ยอดตามงวด / หักหุ้น / รับเงินสด เฉพาะเดือนที่มี
- ช่อง «หักจากทุนเรือนหุ้น» ในฟอร์มรายเดือนใช้กรอกทีละเดือนได้เช่นกัน · ตารางทะเบียนแสดงคอลัมน์ «หักจากหุ้น» เมื่อมีรายการ
- ต้อง Deploy `Code.gs` เวอร์ชันใหม่ เพื่อให้ชีตสรุปรายคนหักหุ้นนี้ออกจากหุ้นสะสมด้วย

### เว็บใหม่: ใบเสร็จรายเดือน (พิมพ์ให้สมาชิกทุกเดือน)

แท็บ **🖨ใบเสร็จรายเดือน** — เลือกเดือนแล้วพิมพ์ใบเสร็จของผู้กู้และผู้ฝากทุกคน ดึงจากรายการที่กรอกไว้ในทะเบียนเดือนนั้น

- หัวใบเสร็จมีตรา กบข.นข. · ตัวอักษร TH Sarabun New (ถ้าเครื่องไม่มีใช้ Sarabun) · จัดหน้าตามหนังสือราชการ ขอบซ้าย 3 ซม. ขวา 2 ซม. ตัวหนังสือชิดซ้าย
- ส่วน «สรุปยอดสะสม»: ยอดยกมา ณ สิ้นเดือนก่อน (ก่อนรับชำระเดือนนี้) → เดือนนี้ (+/−) → คงเหลือ ณ สิ้นเดือน ทั้งทุนเรือนหุ้นและหนี้เงินกู้ (แยกสามัญ/ดูแลกันเมื่อมีสองสัญญา)
- ใบเสร็จแสดง ดอกเบี้ย · เงินต้น · หุ้นประจำ · ฝากเพิ่ม · สะสมเพิ่ม (เฉพาะช่องที่มียอด) แยกตามสินเชื่อสามัญ / ดูแลกัน / ฝากหุ้น + รวมรับ · วันที่รับเงิน · ยอดหุ้นสะสมและหนี้คงเหลือ ณ สิ้นเดือน · ดอกเบี้ยสะสมตั้งแต่ต้นปี · เงินกู้ทับที่ได้รับ (ถ้ามี) · ช่องลงชื่อเหรัญญิก/ประธาน
- เลือกเดือนด้วยรายการหรือปุ่ม ◀ ▶ · กรองผู้กู้/ผู้ฝาก · ค้นชื่อ · ติ๊กเลือกคนที่จะพิมพ์ · ดูตัวอย่างใบก่อนพิมพ์ · «พิมพ์ใบนี้» หรือ «พิมพ์ที่เลือก»
- **ใบเสร็จ 1 คนต่อ 1 หน้า A4** ตัวอักษร 16 pt · วันที่รับเงิน = «ภายในวันที่ 5 {เดือน} {พ.ศ.}» ของเดือนที่ออกใบเสร็จ
- **🗂 ทะเบียนคุมใบเสร็จประจำเดือน** (ปุ่มพิมพ์ในแท็บเดียวกัน) — เลขที่ทะเบียน RG-ปีเดือน · จำนวนใบเสร็จ (ผู้กู้/ผู้ฝาก) · ช่วงเลขที่ใบเสร็จ · ตารางทุกใบ (เลขที่ใบเสร็จ ชื่อ ดอกเบี้ย เงินต้น ฝากหุ้น รวมรับ) พร้อมช่อง «ผู้รับใบเสร็จ ลงชื่อ / วันที่» · ยอดรวมประจำเดือน · ทุนเรือนหุ้น/หนี้คงเหลือรวม · ช่องลงชื่อผู้จัดทำ ผู้ตรวจสอบ ประธาน
- คนที่ไม่มีรายการในเดือนนั้นจะไม่ถูกพิมพ์ · ในหน้าต่างพิมพ์ ให้ปิด «หัวกระดาษและท้ายกระดาษ»

### เว็บใหม่: ทะเบียนผู้กู้ / ทะเบียนผู้ฝาก

แยกจากข้อมูลระบบเก่าทั้งหมด — แต่ละคนมี **บัญชีย่อย 3 อัน**: **สินเชื่อสามัญ** · **สินเชื่อดูแลกัน** · **ฝากหุ้น (ไม่ผูกสัญญา)**

- แต่ละบัญชีย่อยมีหนี้ ทุนเรือนหุ้นของประเภทนั้น งวดละ ตารางผ่อน/คาดการณ์ ฟอร์มบันทึก และนำเข้าตารางผ่อนของตัวเอง (แท็บในหน้ารายคน)
- แท็บ **สรุปรวม** (เปิดเป็นหน้าแรกของแต่ละคน) รวมทุกสัญญา: หนี้รวม · ทุนเรือนหุ้นรวม · ดอกเบี้ยรวม · **เงินคืนสิ้นปี** (ปันผลหุ้น + เฉลี่ยคืนดอกเบี้ย) พร้อมตารางสรุปแยกประเภทและตารางรายเดือนรวม
- หุ้นรวมของคน = หุ้นสามัญ + หุ้นดูแลกัน + หุ้นที่ไม่ผูกสัญญา · ดอกเบี้ยรวมจากทั้งสองสัญญาใช้คิดเฉลี่ยคืนสิ้นปี
- **แยกหนี้/หุ้นยกมา:** ตอนนำเข้าใบสรุป หนี้และหุ้นเดิมเข้า «สามัญ» ทั้งหมด ถ้าใครมีสองสัญญา ไปที่แท็บ «สินเชื่อดูแลกัน» → «แก้ยอดยกมา» ใส่หนี้ดูแลกัน (แล้วลดหนี้สามัญให้รวมเท่าใบสรุป) และหุ้นยกมาของแต่ละประเภท ระบบเตือนถ้ารวมไม่เท่าใบสรุป
- ใบสรุป + ปันผล และชีท Google Sheets แสดงยอดรวมและแยกประเภท
- **งวดที่ 1 ของแต่ละสัญญา กำหนดเดือนเอง** — ในแท็บสามัญ/ดูแลกัน เลือก «งวดที่ 1 เริ่มเดือน» แล้วงวดที่ 2, 3, … นับต่อให้ (ตารางผ่อน ฟอร์ม ตารางคาดการณ์ ใช้เลขงวดของสัญญา · เพดาน 72 งวดนับจากงวดที่ 1) ตารางรวมใช้ «งวดโอน» (พ.ค.68 = 1) เหมือนเดิม
- **🔁 กู้ทับ (ขอกู้ใหม่ระหว่างสัญญา)** — ในฟอร์มของแท็บสามัญ/ดูแลกัน: ใส่ยอดผ่อนของงวดนั้นตามปกติ แล้วกรอก «ยอดกู้ใหม่ (ยอดรวมใหม่)» · จำนวนงวดใหม่ · เดือนของงวดที่ 1 ใหม่ กด «คำนวณงวดละให้»
  ระบบหาเงินส่วนต่างที่ได้รับ (ยอดใหม่ − หนี้คงเหลือ) ตั้งหนี้ใหม่ = ยอดกู้ใหม่ เริ่มงวดที่ 1 ใหม่ ตารางเดิมที่ผ่อนไปแล้วเก็บไว้ (แสดงเป็น «สัญญา 1» «สัญญา 2») ·
  งวดละ = ต้น+ดอกลดต้นลดดอก 1% + หุ้นประจำ + หุ้นเพิ่ม (หุ้นเพิ่ม = อัตราตามจำนวนงวด × ยอดกู้ ÷ จำนวนงวด) แก้ตัวเลขเองได้ · ลบรายการกู้ทับ = คืนค่าเดิม
  - **วางตารางผ่อนที่มีกู้ทบแล้วในครั้งเดียว** — วางตารางสัญญาเดิมต่อด้วยตารางสัญญาใหม่ได้เลย (คั่นด้วยบรรทัดหัวเดือน เช่น `ก.ค. 69` หรือให้งวดที่ 1 เริ่มใหม่) ระบบแยกเป็นสัญญา 1, 2 … แล้วให้ตรวจ/บันทึกทีละสัญญา · สัญญาใหม่เริ่มงวดที่ 1 ที่เดือนนั้น ยอดกู้ใหม่ = คงเหลือ + เงินต้นงวดที่ 1 · บันทึกส่วนต่างที่ได้รับและตั้งงวดละใหม่ให้ · วางเฉพาะตารางสัญญาใหม่อย่างเดียวก็ได้ ระบบรู้ว่าเป็นการกู้ทับต่อจากสัญญาเดิม
  - «สิ้นสุด มิ.ย.69» ท้ายแถวเป็นแค่คำใบ้ — ถ้าชื่อเดือนในแถว งวดที่ 1 ที่ตั้งไว้ หรือยอดคงเหลือที่ตรงกับทะเบียนบอกเดือนไว้แล้ว จะใช้อย่างนั้นก่อน

1. ครั้งแรกกด **เลือกไฟล์ใบสรุป (HTML)** แล้วเลือกใบสรุปชำระรายเดือน พ.ค.–ธ.ค.68
   ระบบอ่าน **หุ้นสะสม** และ **หนี้คงค้าง** ของทุกคน ณ สิ้น ธ.ค.68 เป็นยอดยกมา
   พร้อมประวัติรายเดือนในใบสรุป (แสดงเป็นแถวสีจาง แก้ไม่ได้)
2. คนที่ยังมีหนี้อยู่ในทะเบียนผู้กู้ คนที่ไม่มีหนี้อยู่ในทะเบียนผู้ฝาก — ย้ายเองอัตโนมัติเมื่อหนี้หมดหรือกู้เพิ่ม
3. เลือกคนจากรายชื่อด้านซ้าย เลือกแท็บประเภท (สามัญ / ดูแลกัน / ฝากหุ้น) แล้วบันทึกทีละงวดตั้งแต่งวดที่ 9 (ม.ค.69)
   - ผู้กู้: ชำระรวม · ดอกเบี้ย · เงินต้น · หนี้คงเหลือ / ฝากหุ้นประจำ · ฝากหุ้นเพิ่ม · กู้เพิ่ม — ปุ่ม **แยกยอดให้** คิดดอกเบี้ย 1% ของหนี้ก่อนหน้า → หุ้นประจำ → หุ้นเพิ่ม (ถ้าใส่ไว้) → ที่เหลือเป็นเงินต้น (จ่ายเกินหนี้ใส่เป็นหุ้นเพิ่ม)
   - ผู้ฝาก: ฝากหุ้นประจำ · ฝากหุ้นเพิ่ม — ปุ่ม **ใส่หุ้นประจำ**
   - **ผู้ฝากหุ้น: บันทึกเป็นช่วงเดือนครั้งเดียว** — ในแท็บ «ฝากหุ้น» กล่อง 📅 เลือก «จากเดือน – ถึงเดือน» (ค่าเริ่มต้น เดือนแรกที่ยังไม่บันทึก ถึงเดือนปัจจุบัน) ใส่ฝากหุ้นประจำ/หุ้นเพิ่ม/สะสมหุ้นเพิ่ม (สมัครใจ) ต่อเดือน
     ระบบลงให้ทุกเดือนในช่วง **วันที่รับ = วันที่ 5 ของแต่ละเดือน** · เดือนที่มีบันทึกแล้วข้ามให้ (ติ๊กเขียนทับได้) · ติ๊ก «จำเป็นยอดประจำ» ให้ตารางคาดการณ์ใช้ยอดนี้ · แก้รายเดือนทีหลังได้ในตาราง
   - **กรอกในตารางได้โดยตรง** — ทุกช่องในตารางของแต่ละประเภท (วันที่รับ · ชำระรวม · ดอกเบี้ย · เงินต้น · หุ้นประจำ · หุ้นเพิ่ม · สะสมเพิ่ม · หมายเหตุ) พิมพ์ได้เลย กด Enter / Tab / คลิกที่อื่น = บันทึก ไม่ต้องใช้ฟอร์มด้านล่าง
     แถวที่ยังไม่บันทึกแสดงยอดคาดการณ์เป็นตัวเลขจางๆ ในช่อง (พิมพ์ช่องไหนบันทึกเฉพาะช่องนั้น ระบบไม่ใส่ยอดอื่นให้เอง) · ปุ่ม ⚡ ใส่ตามคาดการณ์ทั้งแถว · ปุ่ม «แยก» แยกยอดชำระเป็นดอกเบี้ย/หุ้น/เงินต้นให้ (ช่องที่พิมพ์ไว้แล้วคงเดิม)
     แก้เงินต้นหรือกู้เพิ่มแล้ว หนี้คงเหลือของแถวถัดไปคิดต่อเนื่องใหม่ให้เอง · ล้างช่องจนแถวว่าง = ลบแถวนั้น (กู้ทับ/ลบแถวทำที่ปุ่ม × และกล่อง 🔁 เหมือนเดิม)
   - **สะสมหุ้นเพิ่ม (สมัครใจ)** — ช่องเพิ่มเติมที่ผู้กู้/ผู้ฝากขอฝากสะสมเอง นอกเหนือจากหุ้นประจำ/หุ้นเพิ่มตามตารางผ่อน: นับรวมในยอดชำระและทุนเรือนหุ้นสะสม มีคอลัมน์ «สะสมเพิ่ม» ในตาราง ตั้ง «สะสมหุ้นเพิ่มเดือนละ» ได้ที่ «แก้ยอดยกมา» เพื่อให้ตารางคาดการณ์และปุ่มแยกยอดใส่ให้
   - ระบบตรวจว่ายอดแยกรวมกันตรงกับยอดชำระ และหนี้คงเหลือถูกต้อง — ในตารางขึ้น ✓ ที่คอลัมน์ «ตรวจ» · ช่องตัวเลขไม่รับค่าติดลบ
4. **งวดโอน** — งวดที่ 1 = พ.ค.68 แต่ละงวดโอนได้ตั้งแต่วันที่ 25 ของเดือนก่อน ถึงวันที่ 5 ของเดือนนั้น
   (งวดที่ 9 = 25 ธ.ค.68 – 5 ม.ค.69 เป็นงวดแรกที่บันทึกในเว็บใหม่) ไล่ต่อไปเรื่อย ๆ
   - กด **📅 ช่วงวันโอนแต่ละงวด** ดูทุกงวด พร้อมจำนวนคนที่บันทึกแล้ว
   - ใส่วันที่รับแล้วระบบบอกว่าโอนในช่วง / โอนช้ากี่วัน / หรือวันที่นั้นเป็นของงวดอื่น (มีปุ่มย้ายงวด)
   - เลยวันที่ 5 แล้วยังไม่มีเงินเข้า นับเป็นค้าง
5. **ตารางถึงงวดที่ 72 (คาดการณ์อัตโนมัติ)** — ตารางของแต่ละคนต่อท้ายด้วยแถวสีจางที่คำนวณให้เอง ไปจนถึงงวดที่ 72 หรือจนหนี้หมด
   - คำนวณต่อจากยอดล่าสุด ด้วยงวดละ + หุ้นประจำ + หุ้นเพิ่มของคนนั้น: ดอกเบี้ย 1% ของหนี้ก่อนหน้า · เงินต้น = งวดละ − ดอกเบี้ย − หุ้น · งวดสุดท้ายปรับให้หนี้หมดพอดี
   - แถว «คาดการณ์» (งวดข้างหน้า) และ «ยังไม่บันทึก» (งวดที่ถึงแล้วแต่ยังไม่ลง) **ไม่นับในยอด ใบสรุป ปันผล หรือ CSV** — ยอดจริงมาจากที่กรอกเท่านั้น
   - กดแถวสีจางเพื่อบันทึกงวดนั้น (ใส่ยอดตามคาดการณ์ให้ แก้ได้ก่อนบันทึก) หรือกด «ใส่ตามคาดการณ์» ในฟอร์ม · บันทึกจริงแล้ว ตารางที่เหลือคำนวณใหม่จากยอดจริงทันที
   - ขึ้นสถิติ «คาดว่าหมดหนี้» (เดือน/งวด/ผ่อนอีกกี่งวด) ถ้าไม่หมดภายในงวดที่ 72 จะเตือนพร้อมบอกว่าต้องส่งงวดละเท่าไร
   - ปุ่ม «+ เพิ่มอีก 12 งวด» ขยายตารางต่อไปเรื่อยๆ · ติ๊กออกเพื่อซ่อนตารางคาดการณ์ · ผู้ฝากคาดการณ์หุ้นสะสมจากหุ้นประจำรายเดือน
6. กดแถวในตารางเพื่อแก้ไข · ยอดยกมาแก้ได้ที่ท้ายหน้าของแต่ละคน
7. **📷 นำเข้าตารางผ่อน** (ปุ่มบนหัวหน้าทะเบียน หรือในหน้ารายคน) — เลือกรูปตารางผ่อนให้ AI อ่าน (ต้องเปิดจากลิงก์ Apps Script และตั้งกุญแจ AI แล้ว)
   หรือวางตารางที่คัดลอกจาก Excel / เว็บ
   - อ่านส่วนหัวของหน้าพิมพ์ «เครื่องคำนวณวงเงินกู้สูงสุด» ด้วย: เลขสมาชิก ชื่อ วงเงิน จำนวนงวด อัตรา ฝากหุ้น/ฝากเพิ่ม ยอดส่งต่อเดือน
   - **เลือกรูปหลายคนพร้อมกันได้** — ระบบดูเลขสมาชิกในรูปแล้วจับคู่ให้ รูปที่ไม่มีส่วนหัว (หน้า 2 ของตาราง) ต่อกับคนเดิม
     แล้วเปิดให้ตรวจ/บันทึกทีละคน (คนที่ 1/5 …) กด «ข้ามคนนี้» ได้
   - จับคู่ «งวดที่ในตาราง» กับงวดโอนจากยอดคงเหลือให้เอง (เลือกเองได้)
   - เติมงวดที่ยังว่างตั้งแต่งวด 9 (ม.ค.69) ถึงงวดปัจจุบัน · ช่องที่อ่านไม่ได้เว้นว่าง · แก้ได้ทุกช่องก่อนบันทึก
   - แถวที่เติมมีป้าย «ตามตารางผ่อน» — กดแถวเพื่อแก้/ใส่วันที่รับ บันทึกแล้วป้ายหายไป
   - ตั้งฝากหุ้น + ฝากเพิ่มตามตารางเป็นยอดประจำของคนนั้น (ใช้กับปุ่มแยกยอดให้)
8. **ลาออก / ลบสมาชิก** — ไม่แสดงในทะเบียน ใบสรุป และชีท · ดู/กู้คืน/ลบถาวรได้ที่ «สมาชิกที่ลาออก» ท้ายรายชื่อ
9. พิมพ์ทะเบียนรายคน / ทั้งหมด (คนละหน้า A4) · ส่งออก CSV
10. นำเข้าใบสรุปใหม่ได้ภายหลัง — เปลี่ยนเฉพาะยอดยกมา รายการที่บันทึกแล้วยังอยู่ครบ

### ใบสรุป + ปันผล

รูปแบบและสูตรตามใบสรุปชำระรายเดือน พ.ค.–ธ.ค.68 เดิม — เลือกช่วงงวดและอัตราได้ (ค่าเริ่มต้น หุ้น 4.50% · ดอกเบี้ย 6.50%)

- ปันผลเงินฝาก/หุ้น = หุ้นสะสมล่าสุดในช่วง × อัตราปันผล × จำนวนเดือน/12
- ปันผลดอกเบี้ยเงินกู้ = ดอกเบี้ยที่ชำระแล้วรวมในช่วง × อัตราเฉลี่ยคืน × จำนวนเดือน/12
- สถานะ: หนี้คงค้างล่าสุดในช่วง > 0 = ผู้กู้ ถ้า = 0 = ผู้ฝาก
- ปุ่มลัด «พ.ค.–ธ.ค.68» ให้ผลตรงกับใบสรุปเดิมทุกคน · «ปี 2569» ใช้ข้อมูลที่บันทึกในเว็บใหม่
- พิมพ์ทั้งหมด (คนละหน้า) / รายคน · ส่งออก CSV · ในหน้าทะเบียนรายคนมีปุ่ม «ใบสรุป + ปันผล»

ใน Google Sheets ได้ชีท **ทะเบียนผู้กู้** (หนึ่งแถวต่อสัญญา), **ทะเบียนผู้ฝาก**, **สรุปรายคน (เว็บใหม่)** (ยอดรวมทุกสัญญา) และ **บันทึกรายเดือน (เว็บใหม่)** เพิ่มให้อัตโนมัติ

### เริ่มต้น: ยอดยกมา ณ สิ้น ธ.ค.68

หน้ากรอกรับชำระ → ปุ่ม **นำเข้ายอดยกมาจากใบสรุป** → เลือกไฟล์ใบสรุปชำระรายเดือน (HTML)

- อ่าน **ทุนเรือนหุ้น** และ **หนี้คงค้าง** ของแต่ละคนจากใบสรุป แล้วแสดงให้ตรวจก่อน ยังไม่บันทึกจนกว่าจะกดยืนยัน
- หนี้คงค้างมากกว่า 0 = ผู้กู้ · เท่ากับ 0 = ผู้ฝาก
- สมาชิกที่มีสัญญาเดียว ตั้งหนี้ยกมาให้สัญญานั้น · ไม่มีสัญญา สร้างบัญชีเงินกู้ยกมาให้ ·
  มีหลายสัญญา แจ้งให้แบ่งหนี้เองที่หน้าคนนั้น
- «งวดละ» ในทะเบียนไม่ถูกเปลี่ยน เว้นแต่ติ๊กให้เปลี่ยนเป็นยอดล่าสุดจากใบสรุป
- นำเข้าซ้ำได้ เขียนทับเฉพาะยอดยกมา รายการที่กรอกไว้ไม่ถูกแตะ
- ไฟล์ใบสรุปเปิดอ่านในเบราว์เซอร์เท่านั้น ไม่ถูกส่งหรือเก็บขึ้น repo

### กรอกทีละคน

แท็บกรอกรับชำระ เปิดมาเป็นแบบ **ทีละคน** (สลับเป็นแบบทั้งงวดได้)

- ซ้ายเป็นรายชื่อ แยกแท็บ **ผู้กู้** กับ **ผู้ฝาก** พร้อมหนี้คงเหลือหรือหุ้นสะสม
- ขวาเป็นฟอร์มของคนที่เลือก งวดตั้งให้เป็นงวดถัดจากที่บันทึกล่าสุดเอง (เริ่ม ม.ค.69)
- ผู้กู้: ใส่ยอดรับ แล้วกด **แยกยอดให้** ระบบแบ่งตามสัญญาข้อ 2.2 — ดอกเบี้ย 1% ของหนี้ก่อนหน้า →
  หุ้นประจำ → หุ้นเพิ่ม → เงินต้น แก้ได้ทุกช่องก่อนบันทึก
- ผู้ฝาก: ใส่ยอดฝาก หรือกด **ใส่ยอดฝากปกติ**
- บันทึกแล้วฟอร์มเลื่อนไปงวดถัดไปเอง · คลิกแถวในประวัติเพื่อแก้

### สมุดรับชำระ — กรรมการกรอกเองทุกช่อง

เงินทุกบาทในระบบมาจากสมุดรับชำระที่กรรมการกรอกเอง ระบบไม่คิดตัวเลขแทน
หนึ่งรายการคือ หนึ่งงวด × หนึ่งคน × หนึ่งสัญญา

| ช่อง | ความหมาย |
|---|---|
| วันที่รับ · ยอดรับรวม | เงินที่รับจริง |
| ดอกเบี้ย · เงินต้น · หุ้นประจำ · หุ้นเพิ่ม · ค่าทวงถาม | แยกยอดรับ ต้องรวมได้เท่ายอดรับรวม |
| หนี้คงเหลือ | หลังหักงวดนี้ ควรเท่ากับหนี้งวดก่อน − เงินต้น |
| ผ่อนผัน · หมายเหตุ | งวดที่ติ๊กผ่อนผันไม่นับเป็นค้าง |

ระบบช่วยแค่ **ตรวจ** และ **สรุป**

- ช่อง «ตรวจ» ของแต่ละแถวเตือนทันทีถ้ายอดแยกไม่เท่ายอดรับ หรือหนี้คงเหลือไม่ต่อจากงวดก่อน
- ปุ่ม «เติมตามงวด» ช่วยกรอกตามงวดละของสัญญา (ดอกเบี้ย 1% ของหนี้งวดก่อน) กดเองเท่านั้น
- ทุกแดชบอร์ด ใบเสร็จ หนังสือเตือน และทะเบียน อ่านจากสมุดนี้ที่เดียว
- งวดถือว่า «ค้าง» เมื่อเลยวันที่ 10 ของเดือนแล้วยังไม่มีรายการ หรือรับน้อยกว่างวดละ

### นำไปใช้ต่อ

- ปุ่ม **ส่งออก CSV** ด้านบน ได้ไฟล์เดียวที่มี สมุดรับชำระ · สรุปรายคน · สรุปรายงวด · ค้างชำระ · ทะเบียนสัญญา
- ทุกแดชบอร์ดมีปุ่มส่งออก CSV ของตารางนั้นเอง
- บน Google Sheets มีชีท **สมุดรับชำระ · สรุปรายคน · สรุปรายงวด** อัปเดตให้เองหลังบันทึก (อย่างน้อยทุก 3 นาที)

### งวด

ระบบสร้างรายการงวดจากข้อมูลจริงทุกครั้งที่วาดหน้าจอ ไล่ตั้งแต่ ม.ค.2568
ถึงเดือนปัจจุบัน และขยายเองตามข้อมูล ไม่ต้องแก้โค้ดเมื่อขึ้นปีใหม่

- เลขงวดของสัญญาเดิมยึดจากงวดอ้างอิง ม.ค.2569 ซึ่งเป็นงวดที่ `t0 + 1`
- งวดก่อนงวดแรกของสัญญา แสดงยอดที่รับจริง แต่ไม่นำมาประเมิน
  เพราะรวมอยู่ในยอดยกมาแล้ว
- งวดที่ยังไม่ถึงกำหนดชำระ (วันที่ 5 บวกผ่อนผัน 5 วัน) ไม่นับเป็นค้างชำระ

## ฝั่งเซิร์ฟเวอร์ — Google Apps Script

[`apps-script/Code.gs`](apps-script/Code.gs) — โค้ดที่วางใน Apps Script ของ Google Sheet ที่เก็บข้อมูล

| หน้าที่ | รายละเอียด |
|---|---|
| เสิร์ฟหน้าโปรแกรม | `doGet` คืน `index.html` ให้เปิดจากลิงก์ `/exec` ได้ตรง ๆ |
| เก็บและอ่านข้อมูล | เก็บทั้งก้อนเป็น JSON ในชีทซ่อน `_ข้อมูล` แบ่งเป็นท่อนละ 4 หมื่นตัวอักษร ฟิลด์ใหม่จึงไม่หล่นหาย |
| ชีทอ่านง่าย | สมาชิก · สัญญา · สมุดรับชำระ · สรุปรายคน · สรุปรายงวด · เงินโอนจากสเตทเมนท์ อัปเดตเองหลังบันทึก |
| อ่านสลิปด้วย AI | ส่งรูปหรือ PDF ให้ Claude แล้วคืนรายการรับโอน บังคับรูปแบบผลลัพธ์ด้วย JSON schema |
| กันชนกัน | `LockService` กันสองคนบันทึกทับกัน |

### ติดตั้ง

1. เปิด Google Sheet ที่จะใช้เก็บข้อมูล → **ส่วนขยาย → Apps Script**
2. วาง `apps-script/Code.gs` ทับไฟล์ `Code.gs` — **ไม่ต้องสร้างไฟล์ HTML** ลิงก์ `/exec` ดึงโปรแกรมล่าสุดจาก GitHub Pages เอง
   (ถ้าดึงไม่ได้ จะใช้ไฟล์ HTML ชื่อ **index** ในโปรเจกต์แทน ถ้ามี)
3. รีเฟรชหน้า Sheet จะมีเมนู **กบข.นข.** ขึ้นมา → **1) สร้างชีททั้งหมด**
4. เมนูเดียวกัน → **ตั้งค่ารหัสเชื่อมต่อ** และ **ตั้งค่ากุญแจ AI**
5. **Deploy → New deployment → Web app** · Execute as: **Me** · Who has access: **Anyone**
5.5 **รหัสเชื่อมต่อ (REMOTE_TOKEN)** — ลิงก์ `/exec` เปิดหน้าโปรแกรมได้ทุกคน แต่ **อ่าน/บันทึกข้อมูลและเรียก AI ต้องใช้รหัส** (ทั้งผ่านหน้า `/exec` และผ่านหน้าอื่น)
   - ตั้งในไฟล์ `Code.gs` บรรทัด `REMOTE_TOKEN_DEFAULT` (หรือที่ Script properties ชื่อ `REMOTE_TOKEN`) ใช้รหัสสุ่มยาว 30 ตัวขึ้นไป
   - เปิดโปรแกรมครั้งแรกบนเครื่องไหน จะถามรหัสหนึ่งครั้ง แล้วจำไว้ในเบราว์เซอร์เครื่องนั้น (ใส่ผิดจะถามใหม่)
   - ⚠ ฉบับใน repo เว้นรหัสว่างไว้ **ห้ามนำ `Code.gs` ที่ใส่รหัสแล้วขึ้น GitHub** — repo เปิดสาธารณะ
   - ในหน้าของแต่ละคนมีปุ่ม **☁ บันทึกขึ้น Google Sheets** สั่งบันทึกทันทีและอ่านกลับยืนยัน
6. **เปิดจากลิงก์ `/exec` เสมอ** — ทุกอย่างที่กรอกบันทึกลง Google Sheets ให้เอง (ปุ่ม ☁ บันทึกขึ้น Google Sheets ที่หัวเว็บไว้สั่งบันทึกทันที)
   - ถ้าเปิดจากไฟล์หรือ GitHub Pages ข้อมูลจะจำไว้แค่ในเบราว์เซอร์นั้น กดปุ่ม ☁ แล้วเลือก «ต่อด้วยรหัสเชื่อมต่อ» หรือ «เปิดลิงก์ /exec»
   - ต่อ Google แล้ว ถ้า Sheets ยังว่างแต่เครื่องนี้ยังจำข้อมูลไว้ ระบบถามว่าจะส่งขึ้น Sheets เลยไหม (ถ้า Sheets มีข้อมูลอยู่แล้ว ไม่ทับ)
   - หน้า GitHub Pages ที่ไม่ได้ต่อ Google และไม่มีข้อมูลค้าง จะพาไปลิงก์ `/exec` เองทันที (ใส่ `?local` ต่อท้าย URL ถ้าต้องการทดลองแบบไม่ต่อ Google)
   - ถ้ามีข้อมูลที่กรอกค้างในเครื่อง ขึ้นแถบแดงพร้อมวิธีกู้: ส่งออกไฟล์สำรอง (JSON) → เปิดลิงก์ `/exec` → กด «นำเข้า» — ระบบ **รวม** รายการที่ขาดเข้าด้วยกัน ไม่ทับของเดิม
7. แก้ `index.html` แล้ว push ขึ้น GitHub — ลิงก์ `/exec` ได้ของใหม่เองภายในไม่กี่นาที
   - ⚠ Apps Script ตัดทุกอย่างที่หน้าตาเหมือน comment ใน `<script>` ทิ้ง แม้จะอยู่ในข้อความ
     ห้ามเขียน `/*` หรือ `//` ในข้อความ (ใช้ `image/\u002a`, `https:\/\/` แทน) — ตรวจก่อน push ด้วย `node tools/gas_strip_check.js`
8. ทุกครั้งที่แก้ `Code.gs` ต้อง **Deploy → Manage deployments → ✏️ → New version → Deploy**

### สองทางที่เปิดโปรแกรมได้

| ทาง | ล็อกอิน | ต้องใช้รหัส | เหมาะกับ |
|---|---|---|---|
| ลิงก์ Apps Script `/exec` | บัญชี Google | ไม่ต้อง | ใช้งานประจำ ปลอดภัยที่สุด |
| GitHub Pages | ไม่ต้อง | ต้องใส่รหัสครั้งเดียวต่อเครื่อง | เปิดจากเครื่องที่ไม่ได้ล็อกอิน Google |

ที่อยู่ `/exec` ฝังไว้ในตัวโปรแกรมแล้ว (ตัวแปร `GAS_URL` ใน `index.html`)
เปลี่ยนที่เดียวเมื่อ Deploy ใหม่แล้วได้ลิงก์ใหม่

**รหัสเชื่อมต่อกับกุญแจ AI ไม่อยู่ในไฟล์ใด ๆ ของ repo นี้** ทั้งคู่เก็บใน Script properties
ของ Apps Script ตั้งผ่านเมนูในหน้า Sheet

## เครื่องมืออ่านสเตทเมนท์

[`tools/nk_statement.py`](tools/nk_statement.py) — อ่านสเตทเมนท์ธนาคารเป็นฐานข้อมูล
รองรับทั้งหน้าที่เป็นข้อความและหน้าที่เป็นรูปภาพในไฟล์เดียวกัน

- **หน้าข้อความ** ดึงคำพร้อมพิกัดด้วย PyMuPDF แล้วจัดเป็นแถวตามตำแหน่ง y
- **หน้ารูปภาพ** เรนเดอร์เป็น PNG แล้วให้ Claude อ่านเป็นข้อความ
  ผลถูกเก็บเป็นไฟล์ `.txt` ไว้ตรวจและแก้ด้วยมือได้ ครั้งต่อไปจะใช้ไฟล์เดิม ไม่เรียกซ้ำ
- **ตรวจทุกบรรทัด** ยอดคงเหลือก่อนหน้าบวกลบยอดรายการ ต้องเท่ากับยอดคงเหลือบรรทัดนั้น
  และผลรวมต้องตรงกับหัวกระดาษของธนาคาร ถ้าไม่ตรงจะรายงาน ไม่ปล่อยผ่าน

### ติดตั้งและใช้งาน

```bash
pip install pymupdf anthropic
```

วางไฟล์ PDF ไว้ในโฟลเดอร์เดียวกัน แล้วสั่ง

```bash
python tools/nk_statement.py
```

ถ้ามีหน้าที่เป็นรูปภาพและยังไม่เคยถอดข้อความ ต้องตั้งกุญแจก่อน

```bash
export ANTHROPIC_API_KEY=sk-ant-...
```

ตัวเลือกอื่น

| ตัวเลือก | ความหมาย |
|---|---|
| `--root <โฟลเดอร์>` | โฟลเดอร์ที่เก็บ PDF วางสคริปต์ไว้ที่ไหนก็รันได้ |
| `--out <โฟลเดอร์>` | โฟลเดอร์ผลลัพธ์ |
| `--ocr-dir <โฟลเดอร์>` | ที่เก็บข้อความที่ถอดจากหน้ารูปภาพ |
| `--members kbk-*.json` | ใส่ชื่อสมาชิกจากไฟล์สำรองของโปรแกรม |
| `--no-ai` | ไม่เรียก AI แม้จะตั้งกุญแจไว้ |
